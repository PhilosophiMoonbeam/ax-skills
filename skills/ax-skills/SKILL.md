# Ax Skills

Use this collection for `@ax-llm/ax` tasks. It has one entrypoint and 18 selectively loaded references. Paths below are relative to this skill root; no original or separately installed Ax skill is required.

## Working policy

1. Identify the requested operation and choose the matching references below. Read only the relevant reference sections; do not preload the collection. Load multiple references only when the task crosses their stated boundaries.
2. Prefer the public factories `ai()`, `s()`, `f()`, `ax()`, `agent()` and `flow()` where the relevant reference supports them. Use specialized classes and APIs when that operation requires them; do not replace public factories with unnecessary construction scaffolding.
3. Follow the selected reference's API shapes, constraints and examples. The source metadata generally records version `25.3.0`; these are source snapshots, not guarantees about the latest package release. For a different installed version, check its package declarations and authoritative documentation before changing an API.
4. Keep secrets out of examples and logs. Before running verification, inspect the repository's scripts and obtain the authorization required by the task. Prefer local type checks and focused tests; do not silently invoke billed model calls, external services, live audio sessions or state-changing operations. Report only checks actually exercised.
